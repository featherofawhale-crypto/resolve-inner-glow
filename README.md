# 内发光 · Inner Glow

免费的 DaVinci Resolve 原生 Fusion 特效。把效果拖到带透明通道的素材上，让主体内部发光，并可添加轮廓外的柔光。所有画面计算由 Resolve 内置 Fusion 节点完成，不依赖第三方 OFX、脚本或网络服务。

**当前版本：v2.10**。已在 macOS Apple Silicon / DaVinci Resolve Studio 19.1.4.11 的剪辑页安装、调参并渲染验证。其他系统和 Resolve 版本尚未实测。

## 安装

下载 [内发光.drfx](内发光.drfx)，双击并在 Resolve 中确认安装。重启 Resolve 后，在「效果库 → 工具箱 → 特效 → WREN → 内发光」找到它。将效果拖到带 Alpha 的片段，随后在检查器的 Fusion 特效页调整参数。

输入需要真正的透明通道；黑色背景本身不是透明。要关闭外圈光晕，取消「启用外溢柔光」，主体发光会保留。旧片段中已有的效果实例不会因安装新版而自动改写参数。

| 参数 | 默认值 |
| --- | --- |
| 亮度 | 1.8 |
| 发光半径 | 16 |
| 内部填色 | 1 |
| 内芯层次 | 0.8 |
| 纹理保留 | 0.08 |
| 主体颜色 | 暖白，RGB 1 / 0.82 / 0.6 |
| 启用外溢柔光 | 开启 |
| 外溢柔光 | 1.5 |
| 外溢范围 | 65 |
| 使用独立外溢色 | 关闭，默认跟随主体颜色 |

## 源码与构建

[内发光.setting](内发光.setting) 是可编辑的 Fusion 模板，[内发光.png](内发光.png) 是效果库缩略图。`内发光.drfx` 只包含这两个文件，安装路径为 `Edit/Effects/WREN/`。修改模板后用 Python 3 标准库重建：

```sh
python3 build.py
python3 -m unittest -v test_package.py
```

构建脚本使用固定 ZIP 元数据，输出 `SHA256SUMS.txt` 方便核对。发布包不包含测试素材、项目文件、渲染缓存或本机路径。

## 验证范围

v2.10 在 Resolve 19.1.4.11 的独立测试工程中验证了剪辑页安装、单个效果条目、默认暖白、外溢柔光开关、输入 Alpha 保留和纯白手动颜色。四组原生 EXR 渲染及九项结果检查通过。不同素材、色彩管理设置、透明边缘和其他 Resolve 版本仍需自行核对。
